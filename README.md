# Good Deeds Calendar

Telegram Mini App для ежедневного учёта добрых поступков. Пользователь отмечает события в календаре, выбирает эмодзи и сохраняет историю непосредственно на устройстве.

## Возможности

- календарное отображение добрых поступков;
- добавление записей с эмодзи;
- локальное сохранение данных;
- адаптация интерфейса под мобильные устройства;
- интеграция с Telegram Mini Apps SDK;
- управление состоянием через Zustand.

## Стек

- React 19;
- TypeScript;
- Zustand;
- Vite;
- Tailwind CSS;
- Telegram Web Apps SDK;
- Jest и Testing Library.

## Локальный запуск

```bash
git clone https://github.com/Richbanker/good-deeds-calendar.git
cd good-deeds-calendar
npm install
npm run dev
```

## Проверка проекта

```bash
npm run lint
npm run test
npm run build
```

## Работа в Telegram

Для публикации приложение необходимо разместить по HTTPS и зарегистрировать URL как Mini App через Telegram BotFather. В браузере проект можно запускать локально как обычное React-приложение.

## Что демонстрирует проект

- разработку мобильного интерфейса на React;
- интеграцию с Telegram Web Apps SDK;
- работу с локальным состоянием и LocalStorage;
- типизацию компонентов и пользовательских данных;
- адаптивную вёрстку.

## Статус

Проект пригоден для дальнейшего развития: синхронизации данных между устройствами, авторизации пользователя и подключения backend-хранилища.
